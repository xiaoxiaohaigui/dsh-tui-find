# dsh-tui-find

![dsh-tui-find 封面](./assets/dsh-tui-find-cover-title.png)

**dsh-TUI 的跨会话全文搜索插件** —— 对本机全部 dsh 会话（zstd 帧链 + 明文 JSONL）做即时增量搜索：命中可读、可复制、可恢复会话。

[English](./README.en.md) · MIT · 零第三方运行时依赖

- 仓库：https://github.com/xiaoxiaohaigui/dsh-tui-find
- npm：https://www.npmjs.com/package/dsh-tui-find

## 这是什么

[dsh-TUI](https://github.com/ccch1mneyyy/dsh-TUI) 有 resume 浏览器、会话内 `/` 搜索与 Ctrl+R 输入历史，但没有跨会话内容检索——对话滚出当前窗口就成了不可搜索的档案。本插件补上这一块：

- **即时**：fzf 式纯内存过滤，结果随扫描流式出现；多词 AND、JS 正则、拼音（全拼/首字母）、标题限定、时间窗口。
- **可读可复制**：split 分栏（左列表 · 右内容，/resume 同款风格）或全屏预览，锚定命中消息、命中词高亮，一键复制原文或日志路径。
- **可恢复**：`↵` 恢复会话，二次确认；右键上下文菜单。
- **侧栏常驻**：同一个单栏列表也住在右侧栏的面板里，侧栏开着就能直接打字搜索、点一行跳进全屏继续读。

![全屏搜索场景：左侧按会话分组的结果列表，右侧只读阅读窗，命中词高亮](./assets/dsh-tui-find-scene.png)

## 安装

```bash
dsh plugin --profile dsh-tui add -w dsh-tui-find@latest
```

`--profile` 换成实际 profile 名（`$DSH_HOME/profiles/` 下的目录名，未设 `DSH_HOME` 时为 `~/.dsh`）。CLI 把包收录进 profile 的 bundle 列表并自动应用包内 `cordis.patch.yml`，无需手动改配置；安装 / 升级 / 卸载后重启 dsh-TUI（或 `/restart`）生效——宿主 `/reload` 不重载插件代码。

本地开发安装：`npm install && npm pack`（prepack 自动构建并跑全量测试），再 `dsh plugin --profile dsh-tui add -w ./dsh-tui-find-<版本号>.tgz`；不要直接安装源码目录。

## 升级与卸载

升级＝重跑安装命令（幂等）；版本未变先 `npm cache clean --force`，重启后用 `/plugins` 验证。卸载：`dsh plugin --profile dsh-tui remove -w dsh-tui-find`，重启生效。

若 profile `package.json → dsh.profile.bundles` 仍残留条目（CLI 版本差异），手动删除即可；`/settings` 保存过的设置在宿主那一侧（≤0.1.6 的 `settings.yaml`，或 ≥0.1.7 的 profile 补丁 `cordis.patch.yml`），重装后继续生效。卸载只影响本插件：会话数据全程只读、不受影响。

## 使用

| 操作 | 说明 |
|---|---|
| `/find <关键词>` | 带参直接出结果（空格分隔多词） |
| `/find` | 空参进全屏搜索场景 |
| `Alt+F` | 全局入口：按一次打开场景，**在场景里再按一次即退出**（`shortcut` 可改键或 `off`） |

### 全屏场景

| 键 | 动作 |
|---|---|
| 任意字符 | 即时过滤；空查询列出最近会话 |
| `↑↓` / `PgUp` `PgDn` | 条目间移动 / 翻页 |
| `Tab` | split 布局：展开 / 收起左侧工作区栏（默认展开，`workspacePane` 可改；范围由栏内选中行决定，见下）；classic 布局：切换范围（本仓库 ⇄ 全部） |
| `Alt+T` | 时间窗口（全部 ⇄ 近 7 天 ⇄ 近 30 天） |
| `Alt+R` / `Alt+N` | 切换正则匹配 / 仅搜索标题 |
| `→` / `←` | split 布局：`→` 聚焦右栏阅读窗，`←` 回到列表、再 `←` 进入工作区栏 |
| `Alt+P` | classic 布局：打开全屏预览（锚定命中消息、命中词高亮） |
| `Alt+C` / `Alt+E` | 复制命中原文 / 折叠、展开当前会话命中（与行尾 `▸ (+N)` 徽标同动作） |
| `Alt+H` | 键位帮助面板 |
| `↵` / `Esc` | 恢复会话（二次确认）/ 清空查询、返回、退出场景 |

鼠标：左键选中、悬停高亮、滚轮按宿主同样的档距移动选择（一档 ≈ 3 行；在阅读窗内则滚动阅读窗，在工作区栏上则移动工作区选择）。命中超过 3 条的会话在最后一条命中行右端显示 `▸ (+N)` 徽标，点它即展开该会话全部命中（展开后同一位置变 `▴ 收起`）——这是唯一一个不跟随整行点击的控件，整行点击仍是"选中并进入恢复确认"。右键开上下文菜单：复制消息文本 / 复制会话日志路径 / 恢复该会话。

- **布局**由 `layout` 配置选择：`split`（默认）在终端 ≥ 100 列时同屏显示"左侧列表 + 右侧会话内容阅读窗"（与 /resume 浏览器同风格）——选中项自动锚定右栏、右栏可独立滚动/复制/右键，`→` 聚焦右栏、`←` 回到列表（`Alt+P` 在 split 下不使用），窄终端自动回退单栏；split 默认就带工作区栏，打开即见"工作区 + 列表 + 阅读窗"（`workspacePane: false` 可改成以双栏打开；场景内 `Tab` 随时收起 / 展开，见下）。`classic` 维持"单栏列表 + `Alt+P` 全屏预览"，那里的 `Tab` 仍是切换范围。
- **阅读窗没有光标**：`↑↓` 逐行滚动、`PgUp`/`PgDn` 与滚轮按档滚动，`n`/`N` 跳到视口之外的上一个/下一个命中（循环回绕）；`Alt+C` 复制的是当前命中（n/N 停驻的那条，或自由滚动后视口上方最近的一条，该会话没有命中时回退视口顶部那条消息）。命中落在消息深处、视口装不下时，阅读窗直接在命中行开窗，而不是停在看不到关键词的消息头。
- **结果**按会话分组、每会话默认展示前 3 条命中（`(+N)` 提示），最近优先；场景打开即开始扫描，结果随会话解析流式出现，头部实时显示进度。
- **预热**：启动约 10 秒后插件在后台预建一次索引（`warmup` 配置可关），此后首次 `/find` 即刻出列表；后台索引期间提示符上方显示"后台索引 n/m"进度行，点按即取消。预热只把冷解码挪到空闲期，不减少总解码量。

### 工作区栏（split 布局）

split 默认展示的第三栏（`workspacePane: false` 时按 `Tab` 展开）就是搜索范围的可见载体：顶部固定「全部会话」，其下每个扫到过的工作区占**两行**（按最近使用排序）——第一行是工作区名（路径末段）与行尾的**会话数**，第二行是完整路径（`~` 表示 home，栏窄时保留尾部）。会话数的口径与检索范围本身一致（普通目录含子目录与 resume 进子目录的反向匹配；home、盘根、UNC 根等容器只做精确匹配）；时间窗口（`Alt+T`）与查询会再筛中间列，所以数字可能大于当下列表里的条数。

| 键 / 操作 | 动作 |
|---|---|
| `←`（从会话列表） | 进入工作区栏；栏收起时先按 `Tab` 展开 |
| `↑↓` / `PgUp` `PgDn` | 移动选择 / 按一屏翻页——**选中即生效**，中间列与右栏阅读窗立刻跟着换 |
| `↵` / `→` | 交回会话列表焦点 |
| `Esc` | 退回上一层（工作区栏 → 列表） |
| 悬停 / 单击 | 只上色 / 选中并交回列表焦点（悬停不改范围，免得光标路过就把范围换掉） |
| 滚轮 | 移动选择（一档 = 宿主的 ±3 行档距，与会话列表同一步）——不必先聚焦，选中即生效 |

- **范围＝选中的工作区**：选「全部会话」等于不设范围；选某个工作区则按该路径匹配（同 cwd、其子目录、以及从子目录 resume 回来的会话），与之前「本仓库」范围是同一套语义，只是从二值变成了列表。
- **整行底色跟随键盘焦点**：工作区的选中行只在栏内聚焦时铺底色；会话列表的选中行也只在列表持有键盘焦点时铺底色。焦点在另一栏（包括阅读窗）时，两者都只保留文字高亮（`❯`、加粗 / 高亮标题），因此一屏只有一个底色焦点。
- **两条提示跟着范围走**：搜索卡右侧的占位符与空结果提示都写出当前范围，深路径保留**尾部**（最末一段名字才是区分点）。
- **初始行**仍由 `defaultScope` 决定（`all` → 全部会话，`repo` → 当前工作区）；从侧栏面板交接过来的范围优先。

### 全局快捷键

默认是 `Alt+F` 而不是 `Ctrl+Shift+F`：主流终端把后者留给自身的"查找"功能并截获按键。冲突时用 `shortcut` 配置改成任意含 `Ctrl` 或 `Alt` 的组合键。

- 入口是**开关**：场景内再按同一个组合键直接退出（不论当时在列表、确认、预览还是帮助层），键位与 `shortcut` 配置一致；`Alt+H` 帮助表里列的就是生效键位，设为 `off` 时该行不显示。
- 把入口改到场景自己也用的键上（`alt+h`/`alt+t`/`alt+n`/`alt+p`/`alt+c`/`alt+e`）**宿主不会拒**，但**入口在场景内优先**：那个键会变成退出而不是它原本的功能。插件会在绑定落地时记一条 warn 并弹一次 toast，场景提示行也会一直标注「已被入口占用」。
- 反过来，**有些组合键宿主自己占着**，改过去不会生效：`alt+r`（宿主的 Continue）、`alt+s`/`alt+v`/`alt+z`，以及 `ctrl+b`/`ctrl+e`/`ctrl+g`/`ctrl+k`/`ctrl+l`/`ctrl+o`/`ctrl+p`/`ctrl+q`/`ctrl+r`/`ctrl+t`/`ctrl+v`/`ctrl+z` 一类（完整集合跟随宿主自己的动作键位）。这种情况注册会被拒绝、**插件保持原来的绑定**（默认仍是 `alt+f`），提示行会写着「未被宿主接受，实际入口 `Alt+F`」——设置卡片仍显示你填的值，以提示行为准。
- 以上提示的 toast 都以 `dsh-tui-find: ` 开头，方便在宿主通知区认出是哪来的。

### 侧栏面板

0.13.0 起 dsh-TUI 有右侧栏，插件会向其中注册一个「搜索」面板（`⌕` 标签），载入的就是上面那张单栏列表：侧栏开着就能搜，不必先开全屏。

| 键 / 操作 | 动作 |
|---|---|
| 任意字符 | 就地编辑查询（面板聚焦时键盘属于面板，未被消费的普通键由宿主吞掉，不会漏进聊天输入框） |
| `↑↓` / 滚轮 | 移动选择（`PgUp`/`PgDn` 按不动，见「已知限制」） |
| `Tab` | 切换搜索范围（本仓库 ⇄ 全部）——与全屏场景同键，状态行用同一句提示确认 |
| `Shift+Tab` / 点行尾 `▸ (+N)` | 折叠、展开当前会话命中 |
| `↵` / 点击**已选中**的行 | 打开全屏 `/find`，带上当前查询、选中行与范围（阅读、复制、恢复都在全屏里） |
| `Esc` | 清空查询；查询已空时交还宿主（焦点回聊天） |
| `←` `→` | 宿主回退键：切换面板（面板唯一不消费的普通键；`z`、数字、`[` `]` `+` `-` 都会被当查询字符吃掉） |
| 悬停 / 单击 | 移动选择 / 选中；选中行再次单击即打开场景 |

**启用与关闭**

- **首次装好没看到面板，就去勾一次**（0.13.0–0.16.1，已发布宿主）：`/settings › 侧栏 › 启用的面板` 里插件面板是一行勾选项（描述写作 `插件面板（act1）`），**勾上即把 `<actN>:search` 写进持久层**，重启后照旧；要调顺序或手写 id，用同页的「高级：编辑原始面板列表」（只收持久形态）。原因：注册只把 id 追加进 `sidePanel.panels` 的**运行时**列表，而这几代宿主随后用持久值整段覆盖它（启动时的配置应用、每次写 `dsh-tui.sidePanel` 都会跑一遍）——0.15.0 起（上游 #1441）会并回已注册未持久化的 id，但 0.16.1 上仍遇到过要勾一次，所以「没看到就勾一次」是唯一可靠的路径。
- **彻底关闭用 `panel: false`**（设置卡片首页有该行）：插件完全不注册；0.16.1 及更早还要把勾选页那一行去掉，否则侧栏会留一个宿主补名的空标签 `Search`（内容区显示第一个已启用面板，宿主语义）——0.17.0（#1695 随包）起不再留这个尾巴，但旧的持久值还在，顺手取消一次即可。
- **上游 #1695 之后（2026-10-22 合入 main，0.17.0 起随包）**：没有可信 Component 身份的面板是**临时项**（`session:act<N>:search`），勾选立即生效、不写持久层；重启时注册自己把它加回来——**不用也不能再「勾一次记住」**。旧版勾出的 `act1:search` 映射不到新号，勾选页会标成「旧匿名地址」，删掉即可。
- 面板 id 由宿主分配，插件只控制 `search` 这一段：`actN` 按激活顺序发号、每次重新注册都可能换号，**别把本机 id 抄进配置**（插件自己只按 `:search` 后缀反查，前缀是什么都不影响）。时机与迁移细节见 `docs/decisions/2026-10-22-host-panel-identity-1695.md`。

**与全屏场景共享**

- 同一个扫描器、同一份内存索引，以及「同一时刻只跑一趟 sweep」的纪律：面板搜索时后台预热让位，打开全屏会中止面板的扫描（回到面板按已预热缓存瞬间重建）。
- 时间窗口 / 正则 / 标题限定 / 拼音沿用配置；**范围**可在面板里用 `Tab` 切换，只作用于本次插件激活、不写回配置——`/find` 与快捷键打开的场景仍从 `defaultScope` 起步，而面板 `↵` 交接过去的场景带着当前范围。
- 宿主只在面板切到前台时挂载，但查询、索引与选择由插件自己持有：切走再切回不丢状态、不重置查询；**每次切回会重扫一趟**（新建会话、刚写进日志的消息都要搜得到）：未变的日志只付一次 stat，增长的从上次偏移续解，1 s 内写过的多付一次重证读；重扫期间列表与选中行原地不动，落定后一次性换新。

**已知限制**

- **`PgUp`/`PgDn` 按不动**（0.13.0–0.16.x，全部已发布宿主）：宿主翻页守卫在 `(key.pageUp || key.pageDown) && fullscreen` 分支里直接 `return`，而这个 `return` 结束的正是面板唯一那条 `useInput` 回调——插件能收到键的分发点 `sidePanel.handleKey` 就在同一回调更下面，永远走不到。插件保留了处理分支，宿主把投递点挪到守卫之前就会自动生效；全屏场景与阅读窗不受影响。
- **收不到 `Ctrl`/`Alt` 组合键**（宿主把它们放行给聊天）：能用的修饰键只有 `Tab` 与 `Shift+Tab`——全屏里折叠用的 `Alt+E` 到不了面板，折叠因此落在 `Shift+Tab`。

**中文输入**：面板把终端光标停在查询框的打字处，输入法候选框贴着面板；这条走宿主内部 hook，取不到时静默降级（候选框回到屏幕底部的聊天输入框），此时可用拼音打 `denglu` 找「登录」，或到全屏场景里输入。查询框空着、且面板持有键盘时，那一行只画光标、不画提示：组词期间插件收不到事件，提示放在那里只会被预上屏挤来挤去。

## 检索范围

- **索引**：用户消息、助手文本、会话标题；`indexTools` 开启后含工具调用摘要，`indexThinking` 开启后含 thinking 文本。
- **匹配**：默认大小写不敏感子串（CJK 天然正确，无分词依赖）；多词 AND（双引号短语保留内部空格、至多 16 词）；正则模式下整个查询是一个模式、不拆词。
- **拼音**（默认开，`pinyin` 可关）：纯字母词同时按拼音匹配汉字——全拼（`zhangsan` → 张三）、默认读音链（`zhongqing` → 重庆）、首字母（`zs` → 张三、`bjdx` → 北京大学，一个字母对一个字、可跨词连续）；全拼从音节起点匹配（不会把上一音节的尾字母接到下一字首字母）；多音字按全部读音参与，ü 按键盘习惯写作 v；内置 3500 常用字读音表，表外字按自身折叠；正则模式不扩展拼音。
- **标题限定**（`Alt+N` 即时切换）：只匹配会话标题、消息正文不参与——适合"找那个会话"；无标题会话不命中。
- **子 agent 会话**（默认不显示，`showSubagentSessions` 可开）：委派给子 agent 的运行各自是一条独立会话日志，默认不进列表也不进搜索索引——理由不是数量而是种类：那是模型自己的工作，不是你打开过的对话，与 `/resume` 浏览器"默认折叠"同一姿态。判据是会话头里的 `origin: subagent`：`/rewind` 分叉会话同样记录父会话却不是子 agent 运行，**始终可见**。隐藏了多少条由头部计数单列（形如「N 个会话 · 已隐藏 M 条子 agent 会话」）。开关只决定是否投递：被过滤的日志照样解码并留在内存索引里，所以打开开关不重读日志、关掉也不丢缓存。
- **默认范围**：本仓库（按会话 cwd 匹配当前工作目录，与 resume 浏览器同语义，含子目录会话）。

## 配置

在 `cordis.patch.yml` 的插件行上覆盖（全部可选）：

```yaml
- insert:
    - id: dsh-tui-find
      name: 'dsh-tui-find'
      defaultScope: 'all'        # 初始范围：repo(默认) | all
      defaultTime: 'all'         # 初始时间窗口：all(默认) | 7d | 30d
      layout: 'split'            # 界面布局：split(默认，左列表+右阅读窗，需≥100列) | classic(单栏+全屏预览)

      caseSensitive: false       # 大小写敏感匹配（默认关）
      regex: false               # 默认启用正则匹配（默认关；场景内 Alt+R 即时切换）
      pinyin: true               # 拼音搜索（默认开；纯字母词同时按全拼/首字母匹配汉字）

      showSubagentSessions: false # 显示子 agent 会话（默认关；/resume 浏览器同样默认折叠）

```

除 `lang` 外的选项都可以在 TUI 内直接改：`/settings` → **dsh-tui-find（会话搜索）** 卡片。卡片分两级：首页留日常旋钮（默认范围、默认时间、界面布局、默认展示工作区、全局快捷键），其余按「匹配方式」「索引」「高级」三张子页收拢，Enter 进入、Esc 返回。0.17.0 起设置屏按页签分组，卡片自带「会话搜索」页签（`Tab`/`Shift+Tab` 或点页签切换），不再和宿主自己的「常规」设置挤在同一页；0.13–0.16 的宿主没有分页，卡片照旧整屏列出。布尔/选择项一改即存，文本项回车确认；卡片文案跟随 TUI 语言。落点随宿主的设置服务世代而变：`@deepseek-ai/dsh-settings` ≤0.1.6 写进 `settings.yaml` 的用户层，≥0.1.7 写进当前 profile 的补丁（`cordis.patch.yml`）。

`lang: auto` 跟随 dsh-TUI 语言链：`DSH_TUI_LANG` → `~/.dsh-tui/lang.json` → 系统 locale → 中文，`/lang` 切换即时生效。

会话根目录按序探测（首个命中即用）：`sessionRoot` 配置（排他覆盖）→ `DSH_TUI_SESSION_ROOT` 环境变量 → `$DSH_HOME || ~/.dsh` + `/sessions` → `~/.dsh-tui/sessions`。

## 隐私与安全

- **全程只读**：只读打开会话日志，不触碰 history lock，不改写历史。
- **落盘最小化**：对话内容只存内存、绝不落盘。唯一例外是水位日志 `~/.dsh-tui/dsh-tui-find/watermark.json`——仅记录路径与字节/修改时间/偏移等元数据、绝无对话文本（0700/0600 + tmp+rename 原子写，`DSH_TUI_FIND_WATERMARK=off` 可关）。
- **世代命名**：dsh 的会话日志按格式世代命名（`session.jsonl`、`session.vN.jsonl`，各有 `.zstd` 压缩变体）。同一会话目录取**编号最高**的世代、同世代内压缩版优先——迁移窗口里并存的旧世代日志不会被索引。
- **增量解码与容错**：追加只解新增帧、同尺寸触碰零解码，缩水/改写/编码翻转自动回退全量；不完整尾帧按 RFC 8878 结构校验跳过，不崩溃、不残留。
- **恢复需确认**：恢复是丢弃当前上下文的破坏性切换，`↵` 二次确认，当前会话工作中给醒目警告。

## 环境要求

- dsh-TUI **≥ 0.13.0**（v0.15 community-draft 插件体系）：0.13.0 是右侧栏与 `ctx.tuiPanels` 的引入线，也是本插件的最低支持版本（`peerDependencies` 同口径）；0.13 之前不再支持，也没有侧栏面板
- 侧栏面板随基线一起到来（0.13.0 起有 `ctx.tuiPanels`）；接缝缺席的宿主构建上仍是零注册、零告警的软降级
- 版本策略与验证口径见 `docs/decisions/2026-10-20-host-baseline-0-13.md`
- Node `^22.19 || >=24`；Windows / macOS / Linux
